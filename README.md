# 結晶の面・方向ビジュアライザー

HTML・CSS・JavaScript だけの静的サイト。依存パッケージのインストールなしで、六方晶の4指数と Fe・Cu・Mg の結晶面・原子列を操作できます。

GitHub Pages 公開・更新・第三者への受け渡しは [PUBLISHING.md](PUBLISHING.md) を参照してください。公開用のファイルは `docs/`、オフライン配布用は `release/crystal-visualizer.zip` です。どちらも `./publish.ps1` で `dist/` から作り直します。

ライセンスは付けていません。改変・再配布の許可は作者が個別に決めます。

## 開く

- サーバー起動中：[指数操作](http://127.0.0.1:4173/) / [元素の原子配列](http://127.0.0.1:4173/atoms.html)
- 再起動：`START.cmd` をダブルクリックし、上記URLをブラウザで開く。停止は起動したウィンドウで `Ctrl+C`。
- サーバーなし：`dist/index.html` をブラウザで開く。外部通信・依存パッケージ・インストールは不要。
- Node.js が別の場所にある場合：このフォルダで `node server.cjs` または `npm start`。
- 4173番ポートが使用中の場合：PowerShellで `$env:PORT = '4174'` を指定して起動。

## 操作

- 六方晶：初期表示は底面中央を原点とし、(1 0 1̄ 0) 面を手前に向けた斜め視点。面 (h k i l)／方向 [w x y z] を切り替え、±ボタンで指数を1ずつ変更。第3指数は自動計算。面・方向とも w、x、y、z を基準に表示。軸比 c/a は理想値 √(8/3) に固定。
- 元素：Fe／Cu／Mgを切り替え。左に単位胞1個分の立体、右に対応する結晶面の平面表示。面内の最密な原子列を Fe で2方向、Cu・Mg で3方向ずつ、両向きの色付き矢印で表示。面と方向の強調を切り替えられる。
- 共通：ドラッグで回転。見やすい大きさの固定縮尺。
- 原子間距離は nm。元素比較では同じウィンドウ幅のとき縮尺を固定。
- 指数操作ページでは方向の矢印を正規化し、終点に原子の模式図を表示。元素比較の原子中心は格子定数に従う。

## 構成

| ファイル | 内容 |
|---|---|
| `dist/index.html`, `app.js`, `geometry.js` | 六方晶の4指数操作と幾何計算 |
| `dist/atoms.html`, `atoms.js`, `materials.js` | 元素比較・原子配列 |
| `dist/style.css`, `atoms.css` | レイアウトと外観 |
| `server.cjs` | 127.0.0.1 のみに接続を限定した静的サーバー |
| `publish.ps1`, `PUBLISH.cmd` | テスト、ZIP 再作成、`docs/` へのローカル展開、必要時の GitHub 送信 |

## 確認

`npm test` または `node --test geometry.test.cjs materials.test.cjs`。

指数操作の125通り×3軸比、原点の位置、既知の方向と面、Fe・Cu・Mgの単位胞内の原子配置・最近接距離・面内原子列、MgのAB積層を検証。

表示モデルの定義とデータ出典は各ページ下部に記載。BCC の {110} は「最も原子が密な面」として扱い、厳密な最密面とは区別。
